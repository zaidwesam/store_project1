# Electronics Store

An Electronics Store is a simple student project developed to simulate an online store for electronic devices and accessories.

The project allows users to browse different electronic products, view product details, and explore available items in an easy and user-friendly interface.

This project was created for educational purposes to practice programming skills, understand basic e-commerce concepts, and gain experience in software development.

## Project Goals
- Display electronic products.
- Organize products into categories.
- Provide a simple and user-friendly interface.
- Practice programming and web development skills.

## Project Type
Student Project – Educational Purpose.
